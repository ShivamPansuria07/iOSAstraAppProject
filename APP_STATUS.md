## How to Run

### Option 1: iOS Simulator (Recommended)
```bash
npm run ios
```
Opens automatically in iOS Simulator

### Option 2: Web Browser (Fastest)
```bash
npm run web
```
Opens at http://localhost:8081

### Option 3: Android Emulator
```bash
npm run android
```
Requires Android Studio and emulator setup

### Option 4: Expo Go (Physical Device)
```bash
npx expo start
```
Then scan QR code with Expo Go app
